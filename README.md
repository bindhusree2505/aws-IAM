# AWS IAM

## Introduction

AWS IAM (Identity and Access Management) is used to securely manage identities and control access to AWS resources.

This repository contains my AWS IAM learning notes, practical implementations, commands, architecture diagrams, security practices, and DevOps use cases.

---

## Topics Covered

* IAM Basics
* IAM Users, Groups and Policies
* IAM Roles
* IAM Policy Evaluation and Least Privilege
* MFA and IAM Security
* IAM with AWS CLI
* IAM DevOps Use Cases

## Practical Work

This repository includes hands-on AWS Console and CLI implementations covering IAM users, groups, policies, roles, permissions, security configurations, and DevOps-related access management.

---

## Goal

To build a strong practical understanding of AWS IAM and learn how to securely manage access to AWS resources using least-privilege principles, IAM roles, policies, and automation.
